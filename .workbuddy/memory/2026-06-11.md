## A 股二八分化数据统计脚本

### 需求
用户有一张截图展示 A 股"二八分化"（大盘=二，小盘=八）各个指数近20日涨跌幅，要求：
1. 用代码统计出来
2. 数据源通过 akshare 获取实时 A 股数据
3. 支持输入日期查询历史数据

### 交付
- `erba_stats.py` — 主统计脚本，支持 `-d YYYY-MM-DD` 和 `-n 周期` 参数
- `erba_viz.py` — 可视化脚本，生成交互式 HTML 图表（Chart.js），页面内置日期选择器和周期选择器
- `erba_viz.html` — 可直接双击在浏览器打开的交互图表

### 使用方式
```bash
python3 erba_stats.py                    # 最新数据
python3 erba_stats.py -d 2026-06-01      # 指定日期
python3 erba_stats.py -d 2026-06-01 -n 10  # 指定日期+10日周期

python3 erba_viz.py                      # 可视化最新
python3 erba_viz.py -d 2026-06-01        # 可视化指定日期
```
